# iPhone 独立 App：计划与当前状态

**当前仓库还没有 iOS 工程或可安装的 iPhone 包。** 安卓 0.2 的小队同步只在安卓客户端实现；Windows 与网页仍为双人旅行。下面是面向“一台 iPhone + 一台安卓手机、旅行时脱离电脑”的实施目标，不代表已交付功能。

## 第一阶段：双人旅行的 iPhone 客户端

- 将现有网页的快速记账界面、邀请码与双人记录格式复用于独立 iOS App。界面资源随安装包提供，断网也能启动。
- 把账本放进可靠的设备本地数据库；保存一笔后立即持久化，关闭应用、重启手机或断网都不丢失。保留按币种计算、原始资金、换汇、还款和单笔删除标记。
- 在 iOS 原生层接入 Bonjour 与 TCP，匹配安卓双人模式的发现服务、加密交换和去重协议。两台手机连同一热点且应用打开时可直接同步，不要求电脑或互联网；热点方向均须用实体 iPhone 与安卓验收。
- 两人相隔且各自有网络时，连接双方都能访问的固定 HTTPS 中转。临时由电脑提供的入口适合试验，不适合“旅行中完全脱离电脑”的长期方案。

## 验收顺序

1. iPhone 独自进入飞行模式，连续记账、结束进程并重启，核对全部旅行和金额仍在。
2. iPhone 与安卓各自无网记录；将其中一台的热点分享给另一台，确认两端到账且重试不重复计账。特别在无蜂窝信号、热点地址变化和局域网权限拒绝后重试。
3. 两机分别处于不同 Wi-Fi 时，通过独立 HTTPS 中转补齐，并核对系统时间、币种和身份。
4. 用真实旅行前完成可安装包的签名、首次启动及备份恢复检查。iOS 测试签名和 TestFlight 均有有效期，不把它们视为永久安装渠道。

## 开发条件

现有 Windows 电脑可继续维护网页与安卓。iOS 编译、签名和真机调试需要 macOS 与 Xcode，可在代码准备后借用 Mac 或使用云端 Mac；旅行中不需要电脑。已安装的 iOS App 仍需在 App 被系统挂起后恢复连接并补同步，不能承诺后台即时传输。

第二阶段才考虑把安卓 0.2 的 2～5 人小队登记与蓝牙 LE L2CAP 协议移植到 iOS。第一阶段先满足当前的一台 iPhone、一台安卓手机的双人旅行。
