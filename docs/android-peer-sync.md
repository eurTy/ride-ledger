# 小队首次登记和附近同步

## 首次登记

- 建队端填写 1～5 人名单并打开旅行，在「旅行 → 邀请同伴」展示二维码。
- 同伴读取二维码，选择自己的名字并确认。Android 可用相机或相册，Windows 可用二维码图片。安卓的「令牌」也可作为备用。
- 两台设备在同一 Wi-Fi 或热点下可自动发现。两台安卓还可通过蓝牙 LE L2CAP 发现和连接。Windows 客户端使用局域网。
- 每个名字绑定一台设备，名额按创建时的名单确定。登记时由建队设备签发凭证，已有成员此后可以在建队设备离线时互相同步。

## 实机检查

1. 在 Windows 和安卓各离线记一笔，重启应用检查账目仍存在。连接同一热点，打开同一小队，核对两笔流水自动出现在两端且没有重复。
2. 用相册读取旧版邀请二维码，连上同一 Wi-Fi 或热点后登记。新版安卓会忽略旧邀请码里的中转地址。
3. 两台安卓可另外在关闭 Wi-Fi 的情况下测试蓝牙。两端应用保持前台，并授予系统要求的附近设备权限。

Windows 和 Android 模拟器已完成小队登记、双向 TCP 补传和重复连接检查。实际 Wi-Fi 发现表现受路由器的设备隔离和 Windows 防火墙设置影响。

旧双人模式的说明见 [v0.1.5 版本源码](https://github.com/eurTy/ride-ledger/tree/v0.1.5)。
