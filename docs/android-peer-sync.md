# 安卓小队首次登记和附近同步

## 首次登记

- 创建小队时填写旅行名称、本人名称和 1–5 人的小队人数。其他成员从「旅行」使用相机或相册读取邀请二维码，也可输入备用令牌。
- 建队设备保持在旅行页面。加入者填写自己的名字。每个名称绑定一台设备，登记数以创建时的小队人数为上限。
- 同一 Wi-Fi 和手机热点使用局域网，蓝牙使用 BLE 发现与 L2CAP 连接。热点可由任意成员开启。登记后设备保存身份，已有成员可以在建队设备离线时互相补传。
- 安卓版只在附近完成首次登记和补传。跨不同 Wi-Fi 时，账目先保存在本机，恢复附近连接后再自动补传。

## 同步与权限

- 首次打开 App 时按系统提示授权。Android 10／11 的后台蓝牙扫描需要把位置权限设为「始终允许」。Android 12 及以上需要「附近设备」权限。权限也可在系统应用设置中修改。
- 进入账本或修改账目会触发同步。系统调度的后台任务按已登记旅行轮转，单次最多检查三趟。周期兜底设为 15 分钟，实际时机由系统决定。两台手机都在后台时，能否发现取决于双方扫描和广播窗口是否重叠。
- Wi-Fi 和热点优先。传不通时尝试蓝牙。传输中断后，已入库批次会保留，重连时继续补齐缺少的记录。复盘右上角可以查看最近验证的队友和连接类型，也可点击重试。

## 真机检查

1. 两台安卓在同一 Wi-Fi 下完成扫码登记。各自离线新增一笔，恢复连接后确认两端补齐且没有重复。
2. 让任意一台手机开启热点，另一台连接。重新打开同一旅行，核对离线账目自动补齐。
3. 关闭 Wi-Fi，打开蓝牙并授予系统权限。在两端前台核对补传，再让其中一端锁屏重复检查。Android 10／11 分别测试有、无后台位置权限的情形。
4. 在完整流水中勾选删除一笔，断线确认删除后重新连接，核对另一端也删除了同一笔，剩余流水仍按时间排列。
5. 准备多批待同步记录，传输时断开一次，再连接检查已接收批次是否保留。另建一趟旅行，检查后台轮转时两趟旅行都能补传。
